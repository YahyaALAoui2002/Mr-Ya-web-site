# Reference material (kept out of the repository)

The client's photos (shop front with the bear, menu board and panels) and the raw chat transcript of the early build session are **not** stored here:
the repository is public, and we do not have the client's written permission to republish their photos. Keep them in a private place (Yahya has the archive
`mrye-private-docs.zip`) and drop them back into this folder when working locally: everything in `docs/reference/` except this file is git-ignored.

What used to be here, by role:
- `shop-front-with-the-bear.png`: the main bear reference (the real mascot, apron, proportions). The bear slices (`src/3d/06-*.js`) are tuned against it.
- `menu-*.png`: photos of the printed menu board; the prices and dish numbers in the page come from them.
- `reference-milk-tea-with-pearls.png`, `icons-flame-and-snowflake.png`: the approved milk render and the temperature badge icons.
- `screenshot-bear-hands-vs-feet-problem.png`: the feedback screenshot that led to the anatomical bear redesign.
- `../transcript/part-1-early-build-session.txt`: raw chat of the first part of the build (summary in `../HISTORY.md`).
